# Feminist-Literature-Engine-ML-Web-Scraping-App-

Feminist Research Recommender System (FemLit AI)
Overview
This project is a data-driven recommender system designed to make feminist research more accessible, discoverable, and actionable. It collects, processes, and analyzes academic papers and books related to feminist studies, and recommends similar content based on textual and semantic features.
The goal is to bridge the gap between complex academic research and users who want relevant, high-quality feminist literature.
Problem Statement
Academic feminist research is often fragmented across platforms and difficult to navigate. Traditional search methods rely heavily on keywords, making it hard to discover related work or explore new perspectives.
This project addresses that by:
	•	Aggregating feminist research data from online sources
	•	Structuring and cleaning the data
	•	Building a recommendation engine based on content similarity
Features
	•	Web scraping and API-based data collection (e.g., OpenAlex, Google Scholar)
	•	Data cleaning and preprocessing using Python (Pandas, NumPy)
	•	Text analysis and feature engineering (TF-IDF / embeddings)
	•	Clustering similar papers using machine learning (e.g., KMeans)
	•	Content-based recommendation system
	•	Data visualization for insights and exploration
Tech Stack
	•	Python (Pandas, NumPy, Scikit-learn)
	•	NLP techniques (TF-IDF, text similarity)
	•	SQL (optional for storage)
	•	APIs & Web Scraping
	•	Data Visualization (Matplotlib / Plotly / Tableau)
	•	Git & GitHub
Methodology
	1.	Data Collection Gather feminist research papers and books via APIs and web scraping.
	2.	Data Cleaning Handle missing values, normalize text, and structure metadata.
	3.	Feature Engineering Convert text data into numerical representations using NLP techniques.
	4.	Clustering Group similar documents using machine learning algorithms.
	5.	Recommendation Engine Suggest similar papers based on user input.
Example Use Case
A user searches for a paper on “gender bias in AI.”
The system returns:
	•	Similar academic papers
	•	Related feminist research topics
	•	Clusters of relevant literature
Key Skills Demonstrated

	•	Machine learning (clustering & similarity models)
	•	NLP and text processing
	•	Data acquisition via APIs and scraping
	•	Analytical thinking and problem framing
	•	Data storytelling and visualization
